Install `p4client-ts` and its Effect peer dependency:

```sh
bun add p4client-ts effect@4.0.4
```

The Effect core and Promise facade run the same operations. Results carry enumerable
`messages`; lists use `items`, and batch failures identify the failed spec.

```ts
import { createP4Client } from 'p4client-ts/promise';

const client = createP4Client({
  connection: { port: 'ssl:perforce:1666', user: 'alice', client: 'alice_ws' },
});
try {
  const pending = await client.listChangelists({ status: 'pending' });
  console.log(pending.items, pending.messages);
} finally {
  await client.dispose();
}
```

Use [Getting Started](/guides/getting-started/) for Promise workflows,
[Effect Service](/guides/effect-service/) for layers and scoped configuration, and
[Testing and Fixtures](/guides/testing-and-fixtures/) for mocks and strict replay.
The root entry is platform neutral; process execution lives in `/node` and `/promise`.
